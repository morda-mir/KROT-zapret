**KROT zapret** — Windows-утилита для работы Discord, YouTube и Telegram.

Выберите нужные сервисы и нажмите **«Включить»**. Остальное KROT настроит
автоматически.

## Как пользоваться

1. Откройте KROT.
2. Отметьте нужные сервисы: Discord, YouTube и/или Telegram.
3. Нажмите **«Включить»**.
4. Дождитесь зелёных индикаторов.

Для проверки голосового канала Discord войдите в любой голосовой канал.
При первом включении Telegram KROT запустит локальный MTProto-прокси и откроет
системную ссылку для его добавления в Telegram. В дальнейшем кнопка со стрелкой
на карточке Telegram повторно откроет эту ссылку.
Если отдельный сервис перестал работать, наведите курсор на его карточку и
нажмите кнопку повторной проверки. KROT заново подберёт для него рабочий
профиль, сохранив уже выбранный профиль второго сервиса.

## Возможности

- Discord: сообщения, медиа и голосовые каналы;
- YouTube: сайт и видео;
- Telegram: локальный MTProto-прокси через WebSocket;
- автоматическая настройка;
- работа в системном трее;
- автозапуск вместе с Windows;
- уведомления о новых версиях;
- подробный журнал для диагностики.

KROT проверяет новые стабильные версии в разделе GitHub Releases при запуске
и затем раз в сутки. Приложение показывает уведомление и открывает страницу
релиза по нажатию; скачивание и установка выполняются пользователем.

## Индикаторы

- **жёлтый** — ожидание или проверка;
- **зелёный** — всё работает;
- **красный** — произошла ошибка, подробности находятся в журнале.
