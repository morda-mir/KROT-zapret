**KROT zapret** — компактная утилита для доступа к Discord и YouTube на
Windows. Она подбирает рабочую конфигурацию Zapret для выбранных сервисов,
запоминает результат для текущей сети и показывает состояние подключения без
лишних технических деталей.

**Версия:** `1.0`

[Последний релиз](https://github.com/morda-mir/KROT-zapret/releases/latest) ·
[Все релизы](https://github.com/morda-mir/KROT-zapret/releases) ·
[Официальный репозиторий Zapret](https://github.com/bol-van/zapret)

## Что умеет KROT

- отдельно включает доступ к Discord и YouTube;
- проверяет сайт, медиа, видео и голосовые каналы;
- автоматически перебирает подходящие стратегии Zapret;
- сохраняет рабочую конфигурацию для текущей сети;
- повторно проверяет соединение после смены Wi-Fi, адаптера или VPN;
- показывает понятные цветные индикаторы вместо технических параметров;
- работает в системном трее и поддерживает автозапуск;
- проверяет наличие новой версии при запуске и затем раз в сутки;
- хранит ограниченные по размеру локальные журналы для диагностики.

## Как это работает

1. Пользователь отмечает Discord, YouTube или оба сервиса и нажимает
   **«Включить»**.
2. KROT сначала проверяет обычный прямой доступ.
3. Если он не работает, KROT проверяет сохранённую конфигурацию, а затем
   перебирает встроенные стратегии Zapret.
4. Рабочая стратегия сохраняется для текущей сети и используется при следующем
   запуске.
5. Во время работы KROT следит за выбранными каналами и повторяет проверку,
   когда сеть меняется.
6. При выключении или полном выходе KROT завершает запущенные им процессы и
   останавливает свою службу.

Для голосового канала Discord проверка начинается после появления голосового
трафика. Пока пользователь не вошёл в голосовой канал, индикатор ожидает
активность. Во время проверки он пульсирует, после подтверждённого ответа
становится зелёным, а при ошибке — красным.

## Индикаторы

- **серый** — канал выключен или ещё не проверен;
- **жёлтый** — ожидание активности;
- **жёлтый пульсирующий** — идёт проверка или подбор стратегии;
- **зелёный** — канал работает;
- **красный** — подключение не подтверждено, подробности есть в журнале.

Если обнаружен сторонний VPN или системный прокси, KROT показывает рядом с
маскотом предупреждение. VPN и прокси могут изменить маршрут трафика и помешать
корректной проверке стратегии.

## Безопасность и приватность

KROT:

- не является VPN;
- не использует собственные серверы;
- не устанавливает системный прокси;
- не отправляет пользовательские журналы;
- обрабатывает только трафик выбранных сервисов;
- управляет только теми процессами Zapret, которые запустил сам;
- проверяет целостность runtime-файлов перед запуском;
- ограничивает размер журналов и автоматически удаляет старые архивы.

Интерфейс работает с обычными правами пользователя. Операции, которым нужны
повышенные права, выполняет отдельная локальная Windows-служба с ручным типом
запуска. После закрытия KROT служба не должна оставаться в памяти.

## Системные требования

- Windows 10 или Windows 11;
- 64-разрядная система;
- права администратора для установки службы и драйвера WinDivert.

## Основа проекта

KROT — независимая графическая оболочка и система автоматического подбора
конфигураций для проекта
[Zapret](https://github.com/bol-van/zapret). Исполняемые компоненты Zapret,
Zapret 2 и WinDivert распространяются на условиях их собственных лицензий.
