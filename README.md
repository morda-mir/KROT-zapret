**KROT zapret** — Windows-утилита для работы Discord и YouTube.

Выберите нужные сервисы и нажмите **«Включить»**. Остальное KROT настроит
автоматически.

## Как пользоваться

1. Откройте KROT.
2. Отметьте Discord, YouTube или оба сервиса.
3. Нажмите **«Включить»**.
4. Дождитесь зелёных индикаторов.

Для проверки голосового канала Discord войдите в любой голосовой канал.

## Возможности

- Discord: сообщения, медиа и голосовые каналы;
- YouTube: сайт и видео;
- автоматическая настройка;
- работа в системном трее;
- автозапуск вместе с Windows;
- уведомления о новых версиях;
- подробный журнал для диагностики.

## Индикаторы

- **жёлтый** — ожидание или проверка;
- **зелёный** — всё работает;
- **красный** — произошла ошибка, подробности находятся в журнале.
