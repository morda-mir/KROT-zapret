**KROT zapret** — простая Windows-утилита для стабильной работы Discord,
YouTube и Telegram. Выберите нужные сервисы и нажмите **«Включить»** — KROT
автоматически настроит подключение для текущей сети.

Все компоненты запускаются локально на компьютере. KROT не является VPN и не
использует собственные серверы.

## Как пользоваться

1. Установите и откройте KROT.
2. Выберите Discord, YouTube и/или Telegram.
3. Нажмите **«Включить»**.
4. Дождитесь зелёных индикаторов.

Для проверки голоса Discord войдите в любой голосовой канал.

При первом включении Telegram KROT запустит локальный MTProto-прокси и предложит
добавить его в приложение Telegram. Повторно вводить настройки не потребуется.
Кнопка со стрелкой на карточке Telegram позволяет снова открыть ссылку
подключения.

Если отдельный сервис перестал работать, нажмите кнопку повторной проверки на
его карточке.

## Возможности

- сообщения, медиа и голосовые каналы Discord;
- сайт и видео YouTube;
- Telegram через локальный MTProto WebSocket-прокси;
- автоматический подбор настроек подключения;
- отдельная повторная проверка каждого сервиса;
- работа в системном трее;
- автозапуск вместе с Windows;
- уведомления о новых версиях;
- подробный журнал для диагностики.

## Индикаторы

- **жёлтый** — ожидание или проверка;
- **зелёный** — сервис работает;
- **красный** — проверка обнаружила ошибку.

## Почему антивирус может показать предупреждение

KROT включает WinDivert, zapret/winws и TG WS Proxy. Эти компоненты работают с
сетевыми пакетами, используют системную службу и сетевой драйвер. Из-за такого
поведения антивирусы могут определять их как `HackTool`, `Riskware` или
показывать эвристическое предупреждение.

Такое предупреждение само по себе не означает заражение. Загружайте KROT только
из официального раздела GitHub Releases и сверяйте SHA-256 установщика. Перед
запуском KROT проверяет целостность встроенных компонентов по сохранённым хешам.

Windows SmartScreen также может показать сообщение «Неизвестный издатель»,
поскольку установщик пока не подписан цифровым сертификатом.

## Обновления

KROT проверяет наличие новых стабильных версий при запуске и затем один раз в
сутки. Приложение показывает уведомление, а скачивание и установку пользователь
выполняет самостоятельно.

## О проекте

KROT использует компоненты:

- [zapret](https://github.com/bol-van/zapret);
- [TG WS Proxy](https://github.com/Flowseal/tg-ws-proxy);
- [WinDivert](https://github.com/basil00/WinDivert).
