# KROT zapret 2.0

Исправление багов и добавлена поддержка Telegram.

## Что изменилось

- Добавлен Telegram через локальный MTProto WebSocket-прокси.
- При первом включении KROT предлагает добавить прокси в Telegram; повторно
  вводить настройки не требуется.
- Добавлены официальный значок Telegram и ссылка на проект TG WS Proxy.
- Упрощено информационное окно и управление приложением через системный трей.
- Одиночный тайм-аут проверки больше не показывает ошибку работающего YouTube.

## Установка

Скачайте `KROT-Setup-2.0-x64.exe` и запустите его. Установщик обновляет
существующую версию с сохранением настроек. Поддерживаются 64-разрядные
Windows 10 и Windows 11.

Антивирус может показать предупреждение для встроенных сетевых компонентов.
Причина описана в README. SHA-256 установщика опубликован рядом с ним.
