# Автономная проверка без VPN

`KROT.FieldTest.exe` нужен для проверки сети в момент, когда связь с рабочей сессией недоступна.

## Порядок

1. Собрать проект в `Debug`.
2. Открыть `src\KROT.FieldTest\bin\x64\Debug\net48\`.
3. Отключить VPN.
4. Запустить `KROT.FieldTest.exe`.
5. Нажать «Начать проверку».
6. После завершения включить VPN.
7. Передать JSON из `%LocalAppData%\KROT zapret\field-tests\`.

Headless-режим:

```powershell
KROT.FieldTest.exe --headless --output C:\Temp\krot-field-test.json
```

## Что проверяется

- наличие VPN, туннельного адаптера или системного прокси;
- DNS;
- TCP-подключение к порту 443;
- TLS с обычной проверкой сертификата и SNI;
- HTTP без системного прокси, cookies и авторизации.

QUIC в этой версии отмечается как `UNSUPPORTED_NET48`: подмена проверки обычным UDP-пакетом дала бы ложный результат.

## Что не сохраняется

- публичный IP;
- SSID, MAC-адреса и имена адаптеров;
- токены, cookies и заголовки авторизации;
- содержимое HTTP-ответов;
- содержимое пользовательского трафика;
- точная геолокация.

Идентификаторы сетевого окружения записываются только как SHA-256.
